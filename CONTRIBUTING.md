# Contributing

GraphLean intentionally stays small: graph contracts, host enforcement, graph-encoded self-evolution, verification, and safe distribution. Do not reintroduce Skills, memory systems, advisor routers, prompt constitutions, or a second scheduler into the core package.

## Development baseline

- Python 3.9+
- Node.js 22.19+ or 24+

Install validation dependencies:

```bash
python -m pip install -r requirements-dev.txt
```

Run the full local gate:

```bash
python -B -m unittest discover -s tests -v
python -B SELFTEST.py
node --check dsh/index.js
npm pack --dry-run --json
```

A host-level claim needs a behavior test. File-existence tests are not enough for authorization, scheduling, rollback, privacy, or session-isolation claims.

Do not commit generated bytecode/caches, local paths, credentials, raw runtime state, or ad-hoc release archives. Build releases only through:

```bash
python -B RELEASE.py --output-dir dist
```
